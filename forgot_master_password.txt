FORGOT MASTER PASSWORD

——————————————————————

If you have forgotten your master password and cannot access the app, you can reset it by deleting the master password file manually.

Steps:
1. Close the application
2. Navigate to the folder where the app is located
3. navigate into the data/ folder first, then delete masterPassword.txt
4. Restart the application
5. The app will open normally without asking for a password

Note: This does NOT delete your saved accounts. Your accounts are stored separately in account.txt and will remain intact.

——————————————————————

To set a new master password, go to:
Menu → Settings → Set master password
